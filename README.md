# UpdatePrice — به‌روزرسانی خودکار قیمت خرید و فروش تتر (USDT)

**UpdatePrice** یک برنامهٔ کنسولی (Console) است که قیمت خرید و فروش **تتر (USDT)** را از یک منبع قیمت می‌گیرد، **کارمزد دلخواه** را روی آن اعمال می‌کند و نتیجه را به پنل صرافی/فروشگاه **AvvalMoney** می‌فرستد. با اجرای مداوم این برنامه، قیمت تتر در سایت شما همیشه به‌روز می‌ماند و تاریخچهٔ قیمت‌ها هم ثبت می‌شود.

## نحوهٔ کار

1. زمان‌بند (DNTScheduler) هر **۱۰ دقیقه** یک‌بار (دقیقه‌های ۰، ۱۰، ۲۰، ۳۰، ۴۰ و ۵۰ از هر ساعت، به وقت ایران) برنامه را فعال می‌کند.
2. قیمت **خرید** تتر از API سرویس **HDPay** گرفته می‌شود.
3. کارمزد خرید (`HDPayBuyPriceCommision`) به آن اضافه شده و قیمت نهایی به API پنل AvvalMoney (`UpdateTetherPrice`) با نوع «خرید» ارسال می‌شود.
4. همین مراحل برای قیمت **فروش** با کارمزد فروش (`HDPaySellPriceCommision`) تکرار می‌شود.
5. اگر هر دو به‌روزرسانی موفق باشد، یک رکورد تاریخچهٔ قیمت (`AddPriceHistory`) در پنل ثبت می‌شود.
6. پیام هر مرحله در کنسول چاپ می‌شود. خطاها و استثناها در فایل XML ذخیره می‌شوند.

## ویژگی‌ها

- به‌روزرسانی خودکار و زمان‌بندی‌شدهٔ قیمت خرید و فروش
- اعمال کارمزد قابل‌تنظیم جدا برای خرید و فروش از طریق `App.config`
- ثبت تاریخچهٔ قیمت (در مخزن داده، فقط وقتی قیمت نسبت به آخرین رکورد تغییر کرده باشد)
- جلوگیری از اجرای هم‌زمان دو نوبت (با مکانیزم `Pause` زمان‌بند)
- ثبت لاگ و خطا در فایل XML
- پشتیبانی آماده از **Nobitex** به‌عنوان منبع قیمت جایگزین (متد آن در کد هست، ولی در جریان اصلی فراخوانی نمی‌شود)

## راه‌اندازی

```bash
git clone https://github.com/DiakoHasani/UpdatePrice.git
```

۱. فایل `UpdatePrice.sln` را در Visual Studio باز کنید و بسته‌های NuGet را بازیابی کنید.

۲. در `App.config` مقدارهای زیر را مطابق نیاز خود تنظیم کنید:

- `HDPayBuyPriceCommision` — کارمزد افزوده‌شده به قیمت خرید
- `HDPaySellPriceCommision` — کارمزد افزوده‌شده به قیمت فروش
- رشتهٔ اتصال به پایگاه داده
- مسیر ذخیرهٔ فایل‌های لاگ XML

۳. پروژه را اجرا کنید (`F5`). برنامه تا زدن یک کلید باز می‌ماند و در این مدت زمان‌بند کار می‌کند.

## نکات

- برنامه باید **همیشه روشن** بماند، مثلاً روی یک سرور یا سرویس ویندوزی.
- زمان‌بندی روی ساعت «UTC + ۳:۳۰» تنظیم شده است.
- قیمت‌ها در پنل فقط وقتی در تاریخچه ثبت می‌شوند که هر دو به‌روزرسانی (خرید و فروش) موفق باشد.
- اگر دریافت قیمت از HDPay شکست بخورد، همان نوبت برای آن نوع (خرید یا فروش) رد می‌شود و نوبت بعدی دوباره تلاش می‌کند.
- اطلاعات حساس (رشتهٔ اتصال، کلیدها) را در مخزن عمومی قرار ندهید.
